VISTORA starter website
1. Open index.html to preview the site in a browser.
2. Before publishing, replace the placeholder email hello@vistora.example in index.html with a real contact email.
3. Replace the three sample project cards with your own completed work. They are clearly marked as concept/practice placeholders.
4. To publish: create a free account on a static hosting provider such as Netlify, then upload this folder (or its ZIP) using the provider's manual deploy flow. A public URL is provided by the host after deployment.
5. This is a static front-end website. It does not include a backend, database, or working contact form. The email link opens the visitor's email app.
